高压氧治疗简介

高压氧治疗（HBOT）：在密闭高压氧舱内，使环境压力高于 1 个绝对大气压（ATA），患者吸入100% 纯氧的物理氧疗方式。

• 核心机制：高压下氧气大量物理溶解于血浆，显著提升血氧分压与组织氧弥散距离，快速纠正缺血缺氧、减轻脑水肿、改善微循环、促进神经修复与侧支循环建立。

• 治疗流程：升压→稳压吸氧→减压；单次约 60–90 分钟，每日 1 次，10–20 次为一疗程。

•临床定位：神经外科康复重要辅助治疗，需与药物、康复训练、护理协同。

神经外科患者高压氧治疗适应症

以生命体征平稳、出血 / 水肿控制为前提，常见适用情况：

1. 颅脑损伤：脑震荡、脑挫裂伤、脑干损伤、弥漫性轴索损伤、颅内血肿术后、外伤后意识障碍 / 认知障碍 / 肢体功能障碍。

2. 脑血管病术后 / 恢复期：脑出血稳定后（无新鲜出血 24–48h）、脑梗死恢复期、蛛网膜下腔出血恢复期、脑血管畸形 / 动脉瘤术后缺血缺氧性脑损害。

3. 脊髓损伤：急性期与康复期，促进感觉 / 运动 / 二便功能恢复。

4. 术后脑水肿、颅内压增高（可控范围内）。

5. 神经功能障碍：认知下降、记忆减退、言语障碍、吞咽障碍、肢体偏瘫 / 麻木。

其他：放射性脑病、颅内良性肿瘤术后神经功能缺损、缺氧缺血性脑病恢复期。

神经外科患者高压氧治疗禁忌症

（一）绝对禁忌症（严禁治疗）

1. 未经处理的气胸、纵隔气肿、肺大疱破裂风险。

2. 活动性颅内出血、出血未控制、新鲜出血灶。

3. 未经控制的癫痫持续状态。

4. 严重肺气肿 / 慢阻肺伴二氧化碳潴留、呼吸衰竭未纠正。

5. 未控制的高热、严重感染性休克、生命体征极不稳定。

6. 服用双硫仑、博来霉素等易增加氧毒性 / 肺毒性药物。

7. 严重心律失常、心力衰竭未控制、主动脉夹层未稳定。

（二）相对禁忌症（严格评估后慎用）

1. 中耳炎、鼻窦炎、咽鼓管功能不良、近期耳部 / 鼻窦手术。

2. 高血压控制不佳（＞160/100mmHg）、冠心病不稳定期。

3. 幽闭恐惧症、精神障碍无法配合。

4. 妊娠、高龄、体质极度虚弱。

5. 癫痫控制可但仍有发作，需严密监护。

高压氧不同压力（ATA）的区别

临床常用1.5–2.5 ATA，压力越高氧供越强，但风险同步增加，神经外科以中低压力为主。

1. 1.5 ATA（微 / 低高压）

◦ 特点：压力温和、耐受性好、气压伤 / 氧中毒风险低。

◦ 适用：轻症脑损伤、康复巩固期、儿童 / 老年 / 不耐受高压者、认知 / 睡眠 / 疲劳改善。

◦ 作用：提升基础氧供、改善脑代谢、辅助康复。

2. 2.0 ATA（标准治疗压力，最常用）

◦ 特点：氧供与安全性平衡，神经修复效率高。

◦ 适用：中重度颅脑损伤、脑出血 / 脑梗恢复期、脊髓损伤、脑水肿控制后、意识障碍促醒。

◦ 作用：显著提高血浆溶解氧、收缩血管减轻水肿、促进神经再生。

1. 2.5 ATA 及以上（高压）

◦ 特点：氧供极强，但氧中毒、气压伤风险上升，需严格控时。

◦ 适用：严重缺氧缺血、一氧化碳中毒、难治性创面（神经外科少用）。

◦ 注意：神经组织娇嫩，不常规用高压，避免加重脑代谢负担。

小结

• 神经外科首选：2.0 ATA；

• 不耐受 / 轻症：1.5 ATA；

• 高压仅用于特殊危重缺氧，不做常规康复。

高压氧与鼻导管吸氧、高流量吸氧、

呼吸机高氧浓度的区别

核心总结

1. 鼻导管 / 高流量 / 呼吸机高氧：常压呼吸支持，解决 “吸不进、氧不够”，不具备高压氧的神经修复、减轻脑水肿、延长氧弥散作用。

2. 高压氧：高压 + 纯氧，以物理溶解氧直达受损脑组织，是神经外科康复的特异性治疗，而非普通吸氧。

3. 顺序逻辑：生命不稳定→呼吸机 / 高流量救命；生命平稳、进入康复→高压氧促进神经功能恢复。

常见注意事项

1. 进舱前：排空大小便、取下金属 / 电子物品、不穿化纤衣物、中耳调压练习（吞咽 / 捏鼻鼓气）。

2. 治疗时机：出血稳定后 24–48h 即可启动；2 周–3 个月黄金期，6 个月内仍获益。

3. 不良反应：耳闷 / 耳痛（调压）、轻微头晕，多可缓解；严重不适立即告知医护。

4. 联合治疗：必须与康复训练、神经营养、并发症管理结合，效果更佳。
